# 🍅 番茄钟

一个单文件、零依赖的番茄钟（纯 HTML/CSS/JS），打开即用。

## 功能

- 三种模式切换：工作 / 短休息 / 长休息
- 每 N 个工作时段自动切换到长休息（默认 4）
- 精准计时（基于墙钟 + rAF，切后台标签页不会漂移）
- 本地统计：今日番茄数、累计番茄数、今日专注时长（存在 localStorage）
- 可配置：工作/短休息/长休息时长、长休息间隔、休息结束是否自动开始下一段
- 声音提醒可一键开关；倒计时结束自动播放蜂鸣
- 键盘快捷键：`空格` 开始/暂停，`R` 重置，`S` 跳过
- 自动统计清理：保留最近 30 天

## 使用

直接打开 `tomato-timer.html` 即可，无需构建、无需服务器。

设置（⚙️）里可以改时长和间隔；🔔 切换声音；🗑 清空全部统计。
